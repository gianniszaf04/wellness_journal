# Πείραμα: τα δύο seeds μαζί και το όριο της Κούρασης

**Δεν χρησιμοποιείται από την εφαρμογή.** Το `main.py` χρησιμοποιεί ένα μοντέλο, το seed 43. Ο φάκελος κρατιέται για να
μπορεί να ξανατρέξει η μέτρηση.

## Ερώτημα

Μπορούμε να βελτιώσουμε το μοντέλο χωρίς νέα δεδομένα και χωρίς training;

1. Βοηθά ο μέσος όρος των πιθανοτήτων των δύο seeds (s42 + s43);
2. Η Κούραση φαίνεται κάτω από το όριο 0,5, ώστε να αρκεί ένα χαμηλότερο όριο;

## Εκτέλεση (από τον φάκελο `Python/`)

```
.venv/bin/python experiments/ensemble/eval_ensemble.py
```

Τρέχει τα δύο μοντέλα με το `main.run_mtl` στο validation (3.566 κείμενα) και στο σετ ελέγχου
(`data/annotation/check_set.csv`, labels από άνθρωπο). Κρατά ~5 λεπτά.

## Αποτέλεσμα (3/11/2026): κανένα από τα δύο δεν βοηθά

Οι κανόνες της απόφασης γράφτηκαν πριν από τη μέτρηση.

| Validation | s42 | s43 | Μαζί |
|---|---|---|---|
| Sentiment macro-F1 | 0,759 | 0,765 | 0,765 |
| Συναισθήματα micro-F1 | 0,568 | 0,574 | 0,575 |
| Διαστρέβλωση F1 (CODIPAD) | 0,721 | **0,761** | 0,747 |
| Τύποι micro-F1 | 0,431 | 0,431 | 0,430 |
| Κίνδυνος στο 0,3: πιάνει / λάθος συναγερμοί | 91 / 32 | 105 / 48 | 106 / 46 |

- **Τα δύο seeds μαζί:** σχεδόν ίδια με το s43, και 0,014 χειρότερα στη διαστρέβλωση. Δεν είναι καθαρά καλύτερα πουθενά,
  ενώ θα χρειάζονταν διπλή μνήμη και διπλό χρόνο.
- **Κούραση:** AUC ≈ 0,5 στο s42, στο s43 και στα δύο μαζί. Η P(Κούραση) δεν είναι ψηλότερη στα κείμενα που ο άνθρωπος
  σημείωσε ως Κούραση. Κανένα όριο δεν βοηθά.
