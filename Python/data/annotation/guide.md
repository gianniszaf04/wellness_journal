# Οδηγός annotation — Test set ημερολογίου (v1)

Ο οδηγός ορίζει πώς γράφονται και πώς παίρνουν labels τα κείμενα του **test set**: 200–300 ελληνικά κείμενα
ημερολογίου, γραμμένα από ανθρώπους, με τα οποία αξιολογείται το μοντέλο. Είναι το «gold standard» της εργασίας.

---

## 1. Βασικοί κανόνες

1. **Το test set δεν μπαίνει ποτέ στο training.** Ούτε ολόκληρο, ούτε κομμάτια, ούτε «παρόμοια» κείμενα.
2. **Δεν στέλνεται σε κανένα LLM** (Gemini, ChatGPT κ.λπ.), ούτε για μετάφραση ούτε για labels.
3. **Συγκατάθεση:** όποιος γράφει κείμενα ξέρει ότι θα χρησιμοποιηθούν σε πτυχιακή και συμφωνεί.
4. **Ανωνυμία:** αλλάζουμε ονόματα, τόπους εργασίας, σχολές ή οτιδήποτε αναγνωρίζει πραγματικό πρόσωπο.
   Οι συγγραφείς καταγράφονται μόνο με ψευδώνυμο (`A01`, `A02`, ...).
5. **Παγώνει:** όταν τελειώσει το annotation, το αρχείο γίνεται `test_v1.csv` και **δεν αλλάζει** αφού δούμε
   αποτελέσματα του μοντέλου. Αν χρειαστεί διόρθωση, φτιάχνουμε `test_v2.csv` και το αναφέρουμε.

---

## 2. Οδηγίες για όσους γράφουν κείμενα

> Γράψε όπως θα έγραφες στο προσωπικό σου ημερολόγιο στο τέλος της μέρας. Δεν υπάρχει σωστό ή λάθος.

- **Πρώτο πρόσωπο**, για τη δική σου μέρα, σκέψεις και συναισθήματα.
- **Μήκος:** από 1–2 προτάσεις έως μια παράγραφο (περίπου 10–200 λέξεις). Θέλουμε και μικρά και μεγάλα.
- **Φυσικά:** όπως γράφεις συνήθως. Ορθογραφικά λάθη, αργκό, emoji, λίγα greeklish είναι **ευπρόσδεκτα**.
- **Μπορεί να είναι φανταστικά** αλλά ρεαλιστικά. Δεν χρειάζεται να είναι πραγματικά σου βιώματα.
- **Μη «στοχεύεις»** κάποιο συναίσθημα με λέξεις-ετικέτες («σήμερα ένιωσα θυμό»). Περίγραψε τι έγινε και τι
  σκέφτηκες, όπως θα το έκανες κανονικά.
- **Θέματα** (διάλεξε ελεύθερα): σχολή/εξεταστική, δουλειά, οικογένεια, φίλοι, σχέση/χωρισμός, υγεία, ύπνος,
  χρήματα, μετακόμιση, χόμπι, αθλητισμός, κατοικίδια, μοναξιά, μια απλή βαρετή μέρα.
- **Δεν ζητάμε** κείμενα για αυτοτραυματισμό ή αυτοκτονία. Αν κάποιος θέλει να μιλήσει για κάτι τέτοιο
  πραγματικά: **1018** (Γραμμή Παρέμβασης για την Αυτοκτονία) ή **10306** (Ψυχοκοινωνική Υποστήριξη), 24/7.

## 3. Στόχοι κάλυψης (για όλο το test set)

| Τι | Στόχος |
|---|---|
| Σύνολο κειμένων | 200–300 |
| Διαφορετικοί συγγραφείς | όσο περισσότεροι γίνεται (ιδανικά ≥ 5) |
| Κάθε συναίσθημα | ≥ 15 κείμενα όπου υπάρχει |
| Κείμενα με 2+ συναισθήματα | ≥ 30% |
| Κείμενα με γνωστική διαστρέβλωση | ~30% |
| Κάθε τύπος διαστρέβλωσης | ≥ 5 κείμενα |
| Ουδέτερα / καθημερινά | ≥ 15% |
| Θετικά | ≥ 20% |
| Μεγάλα κείμενα (> 120 λέξεις) | ≥ 10% |
| Αργκό, λάθη, emoji, greeklish | ~10% |

Κράτα ένα πρόχειρο μέτρημα όσο προχωράς και ζήτα κείμενα εκεί που λείπουν.

## 4. Labels

Βάζεις labels **για τον συγγραφέα**, όχι για τους άλλους που αναφέρει. «Ο Νίκος ήταν έξαλλος» δεν σημαίνει
ότι ο συγγραφέας νιώθει θυμό. Μετράει ό,τι **εκφράζεται ή εννοείται καθαρά** στο κείμενο, όχι υποθέσεις.

### 4.1 Sentiment — ένα από τρία

| Label | Πότε |
|---|---|
| **Θετικό** | Η συνολική διάθεση του κειμένου είναι καλή. |
| **Ουδέτερο** | Περιγραφή χωρίς ουσιαστικό συναίσθημα, ή θετικά και αρνητικά ισορροπούν. |
| **Αρνητικό** | Η συνολική διάθεση είναι κακή. |

**Μικτά κείμενα:** κρίνε από το **συνολικό αποτέλεσμα**, συνήθως από το πώς κλείνει το κείμενο. «Η μέρα ξεκίνησε
χάλια αλλά στο τέλος γέλασα πολύ με τους φίλους μου» → Θετικό. Αν πραγματικά ισορροπεί → Ουδέτερο.

### 4.2 Συναισθήματα — όσα ισχύουν (0 έως πολλά) + το κυρίαρχο

Σημείωσε **όλα** τα συναισθήματα του συγγραφέα που φαίνονται καθαρά. Στη στήλη `dominant_emotion` βάλε το πιο
έντονο ή κεντρικό. Αν δεν υπάρχει κανένα (σκέτη περιγραφή), άφησε και τα δύο κενά και γράψε `κανένα` στο `emotions`.

| Συναίσθημα | Ορισμός | Συνηθισμένα σημάδια |
|---|---|---|
| **Χαρά** | Ευχαρίστηση, ικανοποίηση, κέφι | «πέρασα τέλεια», «γέλασα», «χάρηκα» |
| **Λύπη** | Στεναχώρια, απογοήτευση, πένθος | «μου έλειψε», «έκλαψα», «απογοητεύτηκα» |
| **Θυμός** | Εκνευρισμός, οργή, αδικία | «με εκνεύρισε», «δεν αντέχω που...», «τα πήρα» |
| **Φόβος** | Φόβος για **συγκεκριμένο** κίνδυνο ή απειλή | «φοβήθηκα όταν...», «τρόμαξα» |
| **Άγχος** | Ανησυχία, ένταση για κάτι που **έρχεται** ή αβέβαιο | «αύριο έχω...», «δεν μπορώ να ηρεμήσω», «σφίξιμο» |
| **Ηρεμία** | Γαλήνη, ανακούφιση, χαλαρότητα | «επιτέλους ησύχασα», «χαλάρωσα», «ανακουφίστηκα» |
| **Αγάπη** | Τρυφερότητα, στοργή, ευγνωμοσύνη για πρόσωπα | «τη λατρεύω», «ένιωσα τόσο κοντά του» |
| **Έκπληξη** | Κάτι απρόσμενο (θετικό ή αρνητικό) | «δεν το περίμενα», «έμεινα άφωνη» |
| **Κούραση** | Σωματική ή ψυχική εξάντληση, έλλειψη ενέργειας | «είμαι ράκος», «δεν έχω κουράγιο», «κοιμήθηκα 4 ώρες» |
| **Ενθουσιασμός** | Έντονη, ενεργητική προσμονή ή χαρά | «ανυπομονώ!!», «δεν πιστεύω ότι θα πάμε» |
| **Ντροπή** | Αίσθηση ότι «εκτέθηκα», ότι κάτι δεν πάει καλά **με μένα** | «ήθελα να ανοίξει η γη», «ρεζιλεύτηκα» |
| **Ενοχή** | Αίσθηση ότι **έκανα** κάτι λάθος σε κάποιον/κάτι | «δεν έπρεπε να της μιλήσω έτσι», «τύψεις» |

**Δύσκολα ζευγάρια:**
- **Φόβος ή Άγχος;** Φόβος = συγκεκριμένη απειλή τώρα («ένας σκύλος μου όρμησε»). Άγχος = ανησυχία για το μέλλον
  ή κάτι αόριστο («αύριο εξετάσεις και δεν έχω διαβάσει»).
- **Χαρά ή Ενθουσιασμός;** Ενθουσιασμός μόνο όταν υπάρχει ένταση ή προσμονή. Σε αμφιβολία → Χαρά.
- **Ντροπή ή Ενοχή;** Ντροπή = «είμαι χάλια» (για τον εαυτό). Ενοχή = «έκανα κάτι χάλια» (για μια πράξη).
- **Ηρεμία ή Ουδέτερο;** Ηρεμία μόνο όταν φαίνεται η γαλήνη («τι ωραία ησυχία»). Μια βαρετή μέρα δεν είναι ηρεμία.

### 4.3 Γνωστική διαστρέβλωση — Ναι/Όχι + τύποι

**Διαστρέβλωση** είναι ένας **υπερβολικός ή άκαμπτος τρόπος ερμηνείας** της πραγματικότητας από τον συγγραφέα,
όχι το γεγονός ή το συναίσθημα. Βάζεις **Ναι** μόνο όταν υπάρχει **συγκεκριμένη φράση-σκέψη** που μπορείς να δείξεις.

Σημαντικό:
- **Λύπη ≠ διαστρέβλωση.** «Χωρίσαμε και πονάω πολύ» → Όχι. «Χωρίσαμε, κανείς δεν θα με αγαπήσει ποτέ» → Ναι.
- **Ρεαλιστική ανησυχία ≠ διαστρέβλωση.** «Φοβάμαι μήπως κοπώ, δεν διάβασα αρκετά» → Όχι.
- Αν η σκέψη **αμφισβητείται** μέσα στο κείμενο («μετά σκέφτηκα ότι υπερβάλλω»), βάζεις πάλι **Ναι**: η σκέψη εμφανίστηκε.

Αν **Ναι**, σημείωσε **έναν ή περισσότερους** τύπους:

| Τύπος | Ορισμός | Παράδειγμα |
|---|---|---|
| **Καταστροφολογία** | Το χειρότερο σενάριο ή μεγέθυνση ενός προβλήματος | «Αν κοπώ σε αυτό το μάθημα, τελείωσε η ζωή μου.» |
| **Όλα ή τίποτα** | Σε άσπρο-μαύρο, χωρίς ενδιάμεσο | «Αν δεν πάρω 10, είναι σαν να απέτυχα.» |
| **Υπεργενίκευση** | Ένα γεγονός γίνεται κανόνας («πάντα», «ποτέ», «όλοι») | «Πάλι με απέρριψαν. Πάντα αυτό μου συμβαίνει.» |
| **Ανάγνωση σκέψης** | Βεβαιότητα για το τι σκέφτονται οι άλλοι, χωρίς στοιχεία | «Σίγουρα με βαρέθηκαν, γι' αυτό δεν μου έγραψαν.» |
| **Προφητεία** | Βεβαιότητα για το (αρνητικό) μέλλον | «Ξέρω ότι η συνέντευξη αύριο θα πάει χάλια.» |
| **Συναισθηματική συλλογιστική** | «Το νιώθω, άρα ισχύει» | «Νιώθω άχρηστος, άρα είμαι άχρηστος.» |
| **Πρέπει** | Άκαμπτοι κανόνες για τον εαυτό ή τους άλλους | «Θα έπρεπε να τα προλαβαίνω όλα χωρίς να κουράζομαι.» |
| **Ταμπέλες** | Ολική ετικέτα σε άνθρωπο αντί για συμπεριφορά | «Είμαι ένας αποτυχημένος.» / «Είναι εντελώς ηλίθιος.» |
| **Προσωποποίηση** | Ευθύνη για κάτι που δεν ελέγχεις | «Οι γονείς μου μάλωσαν, σίγουρα φταίω εγώ.» |
| **Νοητικό φίλτρο** | Εστίαση μόνο στο αρνητικό, αγνοείται το θετικό | «Όλοι μου είπαν μπράβο, αλλά εκείνο το ένα σχόλιο τα χάλασε όλα.» |

**Δύσκολα ζευγάρια:**
- **Προφητεία ή Καταστροφολογία;** Προφητεία = «θα πάει άσχημα». Καταστροφολογία = «και θα είναι το τέλος του
  κόσμου». Συχνά συνυπάρχουν: τότε βάλε **και τα δύο**.
- **Υπεργενίκευση ή Ταμπέλες;** «Πάντα τα κάνω λάθος» = Υπεργενίκευση. «Είμαι ανίκανος» = Ταμπέλες.
- **«Πρέπει» που δεν είναι διαστρέβλωση:** «Πρέπει να ψωνίσω γάλα» → Όχι. Μετράει μόνο ως άκαμπτος κανόνας
  με συναισθηματικό βάρος.

### 4.4 Ειρωνεία — Ναι/Όχι (προαιρετικό, για μελλοντική χρήση)

**Ναι** όταν το κείμενο λέει το αντίθετο από αυτό που εννοεί. «Τέλεια, πάλι χάλασε το λεωφορείο, ό,τι ήθελα».
Τα labels sentiment/συναισθήματα μπαίνουν με βάση **το νόημα**, όχι τις λέξεις (εδώ: Αρνητικό, Θυμός).

### 4.5 Κίνδυνος — Ναι/Όχι

**Ναι** μόνο αν ο συγγραφέας εκφράζει σκέψεις αυτοτραυματισμού, θανάτου ή αυτοκτονίας **για τον εαυτό του**.
Δεν ζητάμε τέτοια κείμενα (βλ. §2), αλλά αν εμφανιστεί κάποιο, σημειώνεται. Υπερβολές της καθημερινότητας
(«πέθανα στα γέλια») → Όχι.

---

## 5. Γενικοί κανόνες για αμφιβολίες

1. **Σε αμφιβολία, λιγότερα labels.** Βάλε μόνο ό,τι θα υποστήριζες αν σε ρωτούσαν «πού το βλέπεις;».
2. **Μην κοιτάς** τι label έβαλε άλλος annotator ή τι βγάζει το μοντέλο πριν βάλεις το δικό σου.
3. **Κράτα σημείωση** στη στήλη `notes` για κάθε δύσκολη απόφαση. Βοηθάει στο κεφάλαιο ανάλυσης λαθών.
4. Αν ένας κανόνας του οδηγού δεν σε καλύπτει, **σημείωσέ το**. Ο οδηγός ενημερώνεται (v1.1) πριν παγώσει το test set.

## 6. Μορφή αρχείου

Ένα CSV (UTF-8) με τις στήλες του `test_set_template.csv`. Οι multi-label στήλες χωρίζονται με `|` και
χρησιμοποιούν **ακριβώς τα ονόματα** των πινάκων παραπάνω.

| Στήλη | Τιμές | Παράδειγμα |
|---|---|---|
| `id` | μοναδικό | `T001` |
| `author` | ψευδώνυμο συγγραφέα | `A03` |
| `text` | το κείμενο | `Σήμερα ξύπνησα...` |
| `sentiment` | Θετικό / Ουδέτερο / Αρνητικό | `Αρνητικό` |
| `emotions` | ονόματα με `\|`, ή `κανένα` | `Άγχος\|Κούραση` |
| `dominant_emotion` | ένα όνομα ή κενό | `Άγχος` |
| `distortion` | Ναι / Όχι | `Ναι` |
| `distortion_types` | ονόματα με `\|`, κενό αν Όχι | `Προφητεία\|Καταστροφολογία` |
| `irony` | Ναι / Όχι | `Όχι` |
| `risk` | Ναι / Όχι | `Όχι` |
| `annotator` | ποιος έβαλε τα labels | `J` |
| `notes` | ελεύθερο κείμενο | `μικτό, έκλεισε θετικά` |

---

## 7. Δεύτερος annotator (συμφωνία)

1. Ένα δεύτερο άτομο διαβάζει αυτόν τον οδηγό και βάζει labels σε **50 τυχαία κείμενα**, χωρίς να δει τα δικά σου.
2. Υπολογίζουμε τη συμφωνία (Cohen's kappa για sentiment/distortion, F1 ανάμεσα στους δύο για τα multi-label).
3. Συζητάτε τις διαφωνίες. Αν βγει κανόνας που έλειπε, ενημερώνεται ο οδηγός.
4. Στο test set μένουν τα **δικά σου** labels (ή τα συμφωνημένα). Η συμφωνία αναφέρεται στην εργασία ως το
   «ταβάνι» του προβλήματος: αν δύο άνθρωποι συμφωνούν στο 0.70, δεν περιμένουμε 0.95 από το μοντέλο.

---

## 8. Βήματα

1. Μάζεψε κείμενα (εσύ + συγγραφείς) σε `test_set_template.csv` με συμπληρωμένα μόνο `id`, `author`, `text`.
2. Βάλε labels με βάση αυτόν τον οδηγό. Κάνε διάλειμμα κάθε ~50 κείμενα.
3. Δεύτερος annotator στα 50.
4. Έλεγχος κάλυψης (§3), συμπλήρωση όπου λείπει.
5. Πάγωμα ως `test_v1.csv`.
