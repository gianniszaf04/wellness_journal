# Ημερολόγιο Ευεξίας

Διαδικτυακό ημερολόγιο αυτοβελτίωσης και ψυχολογικής υποστήριξης, στα ελληνικά. Ο χρήστης γράφει για τη μέρα του. Ένα ελληνικό μοντέλο γλώσσας (Greek BERT, multi-task) αναλύει το κείμενο και βγάζει:

- τη διάθεση;
- τα συναισθήματα;
- αν υπάρχει ειρωνεία;
- αν υπάρχει γνωστική διαστρέβλωση;
- αν υπάρχουν ενδείξεις κινδύνου.

Με βάση την ανάλυση, η εφαρμογή δίνει μηνύματα ηρεμίας, γραμμές βοήθειας όταν χρειάζεται και στατιστικά για την πορεία του χρήστη.

> Η εφαρμογή δεν αντικαθιστά επαγγελματία ψυχικής υγείας. Όταν φαίνεται κίνδυνος, δείχνει τις ελληνικές γραμμές βοήθειας (1018, 10306, 112, 116111).

## Λειτουργίες

- **Καταγραφές:**
  - editor με μετρητή χαρακτήρων (έως 10.000) και επιλογή ημερομηνίας;
  - ιστορικό, προβολή, επεξεργασία και διαγραφή κάθε καταγραφής.
  - Σε κάθε αποθήκευση ή επεξεργασία η ανάλυση ξανατρέχει, και ενημερώνονται τα στατιστικά και οι ημερήσιες περιλήψεις.
- **Ζωντανή ανάλυση όσο γράφει ο χρήστης**, χωρίς αποθήκευση: δείχνει τη διάθεση, και τις γραμμές βοήθειας αν φανεί κίνδυνος.
- **Ανάλυση κειμένου** (βλ. [Υπηρεσία AI](#υπηρεσία-ai)):
  - διάθεση (αρνητική, ουδέτερη, θετική) και ένα σκορ από −1 έως 1;
  - 11 συναισθήματα: χαρά, λύπη, θυμός, φόβος, άγχος, ηρεμία, αγάπη, έκπληξη, ενθουσιασμός, ντροπή, ενοχή. Το μοντέλο βγάζει και ένα 12ο, την κούραση, αλλά η εφαρμογή **δεν τη δείχνει**, γιατί σε πραγματικά κείμενα δεν τη βρίσκει (βλ. [Αποτελέσματα](#αξιολόγηση-και-αποτελέσματα));
  - ειρωνεία ή χιούμορ;
  - γνωστικές διαστρεβλώσεις κατά τη CBT, σε 10 τύπους (καταστροφολογία, όλα ή τίποτα, υπεργενίκευση, ανάγνωση σκέψης κ.ά.);
  - ενδείξεις αυτοτραυματισμού ή αυτοκτονικού ιδεασμού.
- **Σημειώσεις στην καταγραφή:**
  - Η σημείωση για την ειρωνεία φαίνεται.
  - Η σημείωση για τη διαστρέβλωση **είναι κρυφή από προεπιλογή** (`SHOW_DISTORTION_NOTE=0`), γιατί σε πραγματικά κείμενα βγαίνει συχνά λάθος (βλ. [Αποτελέσματα](#αξιολόγηση-και-αποτελέσματα)). Η βάση την αποθηκεύει κανονικά.
- **Πρόσωπα και μέρη (NER)** στις καταγραφές, με spaCy: στα στατιστικά φαίνεται πόσες φορές αναφέρεται κάθε πρόσωπο και ποιο συναίσθημα συνοδεύει συνήθως.
- **Υποστήριξη σε κρίση:**
  - **Κρίση:** οι γραμμές 1018, 10306, 112 και 116111 εμφανίζονται όταν η πιθανότητα κινδύνου είναι ≥ 0,3 **ή** όταν το κείμενο περιέχει φράσεις αυτοτραυματισμού. Ο έλεγχος με τις φράσεις δουλεύει και όταν η υπηρεσία AI δεν απαντά.
  - **Πολύ χαμηλή διάθεση:** εμφανίζεται ένα ήπιο μήνυμα με τη γραμμή 10306.
- **Εργαλεία ηρεμίας:**
  - μήνυμα ενθάρρυνσης μετά την αποθήκευση, ανάλογα με το κυρίαρχο συναίσθημα και την ένταση (όχι σε κρίση);
  - ήχος την ώρα της γραφής, που διαλέγεται στο προφίλ: «Φύση» (νερό και άνεμος), «Εστίαση» (χαμηλός θόρυβος) ή «Ανάσα» (οδηγός αναπνοής: 4 δευτερόλεπτα εισπνοή, 6 εκπνοή);
  - φωτεινό και σκοτεινό θέμα.
- **Στατιστικά:**
  - η διάθεση ανά μέρα και ο μέσος όρος, με σύγκριση με την προηγούμενη περίοδο;
  - μέσος όρος ανά μέρα της εβδομάδας;
  - κατανομή συναισθημάτων;
  - συνεχόμενες μέρες καταγραφής;
  - τα πρόσωπα που αναφέρονται πιο συχνά.
- **Insights:** ειδοποίηση όταν η διάθεση μιας καταγραφής πέσει κάτω από το όριο (`SENTIMENT_WARNING_THRESHOLD`), το πολύ μία την ημέρα.
- **Λογαριασμός:**
  - εγγραφή με επιβεβαίωση email (κωδικός 6 ψηφίων) και επαναφορά κωδικού με email;
  - αλλαγή κωδικού και εξαγωγή όλων των δεδομένων σε JSON;
  - διαγραφή λογαριασμού με περίοδο 30 ημερών για επαναφορά.

## Αρχιτεκτονική

```
  Browser (HTML/CSS/JS, Chart.js)
          |
          |  HTTP / JSON
          v
  Apache + PHP 8  (public/index.php, front controller)
          |                         |
          |  PDO                    |  cURL, POST /analyze
          v                         v
  MariaDB                     Python FastAPI (127.0.0.1:8000)
                                GreekBERT multi-task + spaCy NER
```

- Το PHP εξυπηρετεί τις σελίδες και το REST API. Όλα τα αιτήματα περνούν από το `public/index.php`. Το `.htaccess` σερβίρει απευθείας μόνο τον φάκελο `public/`.
- Η υπηρεσία AI ακούει μόνο τοπικά. Την καλεί μόνο το PHP, μέσω του `App/Services/AiClient.php`.
- Το PHP κρατά μόνο τα αποτελέσματα των tasks που έχουν εκπαιδευτεί. Τα υπόλοιπα τα αγνοεί.
- Πριν καλέσει την υπηρεσία AI, το PHP αφήνει το session, ώστε μια αργή ανάλυση να μην μπλοκάρει τις άλλες σελίδες του χρήστη.

## Εγκατάσταση

### Προαπαιτούμενα

- XAMPP με PHP 8+ (με την επέκταση cURL) και MariaDB 10.4+
- Python 3.11
- Το project μέσα στο `htdocs`, π.χ. `/Applications/XAMPP/xamppfiles/htdocs/wellness_journal`
- Λογαριασμός SMTP για τα email επιβεβαίωσης (π.χ. Gmail με app password)

### 1. Ρυθμίσεις

```bash
cp .env.example .env
```

Συμπληρώστε τουλάχιστον:

- τα `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`;
- τα `MAIL_*`, αλλιώς δεν μπορεί να ολοκληρωθεί η εγγραφή;
- το `APP_KEY`, το κλειδί που κρυπτογραφεί τα κείμενα. Το φτιάχνει η εντολή `php bin/encrypt_texts.php --key`.

Κρατήστε αντίγραφο του `APP_KEY` έξω από τον server. Αν χαθεί ή αλλάξει, τα κείμενα που έχουν ήδη γραφτεί δεν διαβάζονται ξανά.

Δείτε την ενότητα [Ρυθμίσεις](#ρυθμίσεις-env).

### 2. Βάση δεδομένων

Πρώτη εγκατάσταση, με τον χρήστη root. Στο `create_user.sql` ορίστε πρώτα τον ίδιο κωδικό με το `DB_PASS`.

```bash
mysql -u root < database/create_user.sql
mysql -u root < database/schema.sql
mysql -u root < database/seed.sql
```

Το `schema.sql` μπορεί να ξανατρέξει με ασφάλεια. Οι αλλαγές σε υπάρχουσα βάση γίνονται με migrations:

```bash
MIGRATE_DB_USER=root MIGRATE_DB_PASS= php database/migrate.php            # τρέχει όσα δεν έχουν τρέξει
MIGRATE_DB_USER=root MIGRATE_DB_PASS= php database/migrate.php --status   # δείχνει την κατάσταση
```

### 3. Υπηρεσία AI

```bash
cd Python
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install https://github.com/explosion/spacy-models/releases/download/el_core_news_md-3.7.0/el_core_news_md-3.7.0-py3-none-any.whl
.venv/bin/python main.py
```

Τα βάρη του μοντέλου (`Python/mtl_model.pt`, ~450 MB) και το `Python/mtl_config.json` **δεν είναι στο repository**. Βγαίνουν από την [εκπαίδευση](#δεδομένα-και-εκπαίδευση). Χωρίς αυτά η υπηρεσία ξεκινά, αλλά το PHP δεν κρατά κανένα αποτέλεσμα του μοντέλου. Μένουν τα ονόματα (NER) και ο έλεγχος κινδύνου με τις φράσεις.

Η υπηρεσία ξεκινά στο `http://127.0.0.1:8000`. Έλεγχος κατάστασης:

```bash
curl http://127.0.0.1:8000/health
```

### 4. Εκκίνηση

Ξεκινήστε Apache και MariaDB από το XAMPP και ανοίξτε `http://localhost/wellness_journal`.

## Υπηρεσία AI

Ένα multi-task μοντέλο πάνω στο Greek BERT (Koutsikakis και συν., 2020), με ξεχωριστό head για κάθε task:

| Task               | Τύπος        | Έξοδος                                   | Απόφαση                              |
|--------------------|--------------|------------------------------------------|--------------------------------------|
| `sentiment`        | single-label | Αρνητικό, Ουδέτερο, Θετικό + σκορ −1…1   | η πιο πιθανή κλάση                   |
| `emotion`          | multi-label  | 12 συναισθήματα                          | όσα έχουν πιθανότητα ≥ 0,5           |
| `irony`            | binary       | Όχι, Ναι                                 | Ναι αν P > 0,5                       |
| `distortion`       | binary       | Όχι, Ναι                                 | Ναι αν P > 0,5                       |
| `distortion_types` | multi-label  | 10 τύποι γνωστικής διαστρέβλωσης         | όρια από το training (0,4–0,5), μόνο αν distortion = Ναι |
| `risk`             | binary       | Όχι, Ναι + πιθανότητα                    | το PHP δείχνει βοήθεια αν P ≥ 0,3    |

**Μεγάλα κείμενα:**

- Το κείμενο κόβεται σε κομμάτια των 128 tokens, με επικάλυψη 32 tokens και έως 32 κομμάτια.
- Η διάθεση βγαίνει ως μέσος όρος των κομματιών, σταθμισμένος με το μήκος τους.
- Τα συναισθήματα παίρνουν τη μέγιστη πιθανότητα από όλα τα κομμάτια.
- Η ειρωνεία, η διαστρέβλωση και ο κίνδυνος βγαίνουν από το κομμάτι με τη μεγαλύτερη πιθανότητα για «Ναι».

**Ετικέτες:** ορίζονται στο `Python/labels.py`. Αν αλλάξουν, το μοντέλο πρέπει να ξαναεκπαιδευτεί. Η υπηρεσία το ελέγχει στην εκκίνηση με το `mtl_config.json`.

**NER:** spaCy `el_core_news_md`, με lemmatization, ώστε «του Γιάννη» και «ο Γιάννης» να μετρούν ως ένα πρόσωπο. Κρατά πρόσωπα, οργανισμούς, τοποθεσίες, γεγονότα και αντικείμενα.

**Endpoints:**

- `GET /health`: κατάσταση, αν φορτώθηκαν βάρη, ποια tasks είναι εκπαιδευμένα, συσκευή (CPU, CUDA, MPS)
- `POST /analyze` με σώμα `{"text": "...", "known_words": [...]}`: πλήρης ανάλυση, οντότητες, και έως 5 λέξεις με
  προτάσεις ορθογραφίας (`spelling`). Το `known_words` είναι προαιρετικό: οι λέξεις του προσωπικού λεξικού
- `POST /spelling` με το ίδιο σώμα: μόνο οι προτάσεις ορθογραφίας, χωρίς μοντέλο, έως 50 λέξεις, για την ώρα που
  γράφει ο χρήστης

**Ορθογραφία:** το τελικό `σ` γίνεται `ς` μόνο του, στο κείμενο που πάει στο μοντέλο. Οι άλλες λέξεις που λείπουν από το
λεξικό παίρνουν έως 3 προτάσεις, με τόνους, και διαλέγει ο χρήστης. Το λεξικό (elspell και συχνότητες από υπότιτλους)
φτιάχνεται με το `experiments/spelling/build_dictionary.py`. Λεπτομέρειες στο `experiments/spelling/README.md`.

**Χωρίς βάρη:** χωρίς αρχείο βαρών (`mtl_model.pt`) η υπηρεσία λειτουργεί, αλλά οι προβλέψεις είναι τυχαίες. Το PHP τις απορρίπτει, εκτός αν `AI_ALLOW_UNTRAINED=1`.

## Δεδομένα και εκπαίδευση

**Τα datasets δεν περιλαμβάνονται στο repository.** Κάθε script `prepare_*.py` αναφέρει στην κεφαλίδα του από πού κατεβαίνει η πηγή.

| Πηγή          | Άδεια        | Γλώσσα                    | Tasks                          | Γραμμές (train / val) |
|---------------|--------------|---------------------------|--------------------------------|-----------------------|
| SentiMP-Gr    | CC BY-SA 4.0 | Ελληνικά                  | sentiment                      | 380 / 111             |
| XED (el)      | CC BY 4.0    | Ελληνικά                  | emotion, sentiment             | 2.760 / 646           |
| GoEmotions    | Apache 2.0   | Αγγλικά → μετάφραση       | emotion, sentiment             | 3.125 / 764           |
| CODIPAD       | CC BY 4.0    | Αγγλικά → μετάφραση       | distortion, distortion_types   | 3.121 / 710           |
| Reddit C-SSRS | CC BY 4.0    | Αγγλικά → μετάφραση       | risk                           | 7.442 / 1.332         |
| Συνθετικά     | —            | Ελληνικά, από Gemini      | όλα, κυρίως irony και κούραση  | 2.190 / 0             |
| Χειρόγραφα    | —            | Ελληνικά                  | όλα                            | 15 / 3                |

**Σημειώσεις για τα δεδομένα:**

- **Μετάφραση και έλεγχος labels:** οι αγγλικές πηγές μεταφράστηκαν με το Gemini. Τα labels του CODIPAD, του C-SSRS και του GoEmotions ελέγχθηκαν ξανά σε ξεχωριστή κλήση, με τους ορισμούς του οδηγού `data/annotation/guide.md`.
- **Συνθετικά κείμενα:** είναι ημερολόγια που γράφτηκαν για τα κενά των πηγών: ειρωνεία, κούραση, μικτές μέρες, ηρεμία, και αρνητικά κείμενα χωρίς διαστρέβλωση. Κρατήθηκαν μόνο όσα πέρασαν έναν τυφλό έλεγχο labels, και ένα δείγμα ελέγχθηκε από άνθρωπο. Μπαίνουν **μόνο στο train**, ώστε το validation να έχει μόνο πραγματικά κείμενα.
- **Δημόσια κείμενα μόνο:** στο Gemini στέλνονται μόνο δημόσια datasets, ποτέ καταγραφές χρηστών της εφαρμογής.

Ροή, από τον φάκελο `Python/` (με `GEMINI_API_KEY` στο `.env` για τα βήματα 2–4):

```bash
# 1. Προετοιμασία κάθε πηγής -> data/interim/
.venv/bin/python data/prepare_sentimp.py
.venv/bin/python data/prepare_xed.py
.venv/bin/python data/prepare_goemotions.py
.venv/bin/python data/prepare_codipad.py
.venv/bin/python data/prepare_cssrs.py

# 2. Μετάφραση των αγγλικών πηγών -> data/processed/
.venv/bin/python data/translate_gemini.py --dry-run
.venv/bin/python data/translate_gemini.py

# 3. Δεύτερος έλεγχος labels με τους ορισμούς του οδηγού (codipad, cssrs, goemotions)
.venv/bin/python data/check_labels.py --source codipad
.venv/bin/python data/check_labels.py --source codipad --apply full

# 4. Συνθετικά κείμενα ημερολογίου, με τυφλό έλεγχο labels
.venv/bin/python data/generate_synthetic.py --dry-run
.venv/bin/python data/generate_synthetic.py
.venv/bin/python data/generate_synthetic.py --review 40     # δείγμα για έλεγχο από άνθρωπο

# 5. Συγχώνευση, έλεγχος ετικετών, split ανά group -> training/train.csv
.venv/bin/python data/merge_dataset.py

# 6. Εκπαίδευση -> mtl_model.pt, mtl_config.json, runs/<ημερομηνία_ώρα>/run.json
.venv/bin/python training/train_mtl.py --seed 43 --min-examples 200 --note "τι άλλαξε"
```

**Σημειώσεις:**

- **Συνέχεια:** η μετάφραση και τα συνθετικά συνεχίζουν από εκεί που σταμάτησαν, αν διακοπούν.
- **Split:**
  - Το `merge_dataset.py` χωρίζει train και validation ανά group (ίδιος χρήστης ή ίδια ερώτηση), με hash, ώστε το split να μένει ίδιο όταν μπαίνουν νέα δεδομένα.
  - Αφαιρεί ό,τι υπάρχει στο test set (`data/annotation/test_*.csv`), ώστε να μη μπει ποτέ στην εκπαίδευση.
- **Εκπαίδευση** (δείτε το `run.json` κάθε run για όλες τις τιμές):
  - 10 εποχές, batch 16, learning rate 2e-5 για το BERT και 1e-4 για τα heads;
  - βάρη κλάσεων για sentiment και risk, και `pos_weight` για τα multi-label;
  - κρατιέται η εποχή με τον καλύτερο μέσο όρο στα tasks με ≥ 200 γραμμές στο validation;
  - τα όρια των multi-label βγαίνουν με τον κανόνα 1-SE γύρω από το 0,5.
- **Μοντέλο της εφαρμογής:** το 4ο training με seed 43 (`runs/2026-11-02_131743/`).
- **Χωρίς `train.csv`:** αν δεν υπάρχει `training/train.csv`, η εκπαίδευση χρησιμοποιεί το χειρόγραφο `training/dataset.csv`.

## Αξιολόγηση και αποτελέσματα

Υπάρχουν τρία επίπεδα μέτρησης:

1. **Validation:** 3.566 κείμενα των πηγών, χωρίς συνθετικά, με τα labels των πηγών. Τα περισσότερα είναι μεταφρασμένα, εκτός από SentiMP-Gr και XED. Μετριέται με το `training/evaluate_mtl.py`.
2. **Σετ ελέγχου:** 200 κείμενα του validation, με labels από άνθρωπο για τη διαστρέβλωση και την κούραση (`data/make_check_set.py`, `training/eval_check_set.py`). Στο git μπαίνουν μόνο τα labels και τα ids, χωρίς τα κείμενα.
3. **Test set:** ~300 ημερολόγια γραμμένα από ανθρώπους, με labels από δύο άτομα κάθε φορά. **Βρίσκεται σε εξέλιξη.**
   - Δεν το διαβάζει κανένα LLM.
   - Χρησιμοποιείται μία φορά, στο τέλος.
   - Οδηγίες: `data/annotation/guide.md` και `writing_instructions.txt`.

```bash
.venv/bin/python training/evaluate_mtl.py --out eval_val.json
.venv/bin/python training/eval_check_set.py
```

**Validation, μοντέλο της εφαρμογής (seed 43):**

| Task            | Μέτρο                                  | Τιμή            |
|-----------------|----------------------------------------|-----------------|
| Sentiment       | macro-F1                               | 0,765           |
| Emotion         | μέσος F1 ανά label / micro-F1          | 0,588 / 0,574   |
| Distortion      | macro-F1 στο CODIPAD                   | 0,771           |
| Distortion types| micro-F1                               | 0,435           |

| Irony           | —                                      | δεν μετριέται: υπάρχουν μόνο συνθετικά δεδομένα |

**Τι έδειξε το σετ ελέγχου (labels από άνθρωπο):**

- **Διαστρέβλωση:**
  - Το μοντέλο λέει «Ναι» σε 83 από τα 200 κείμενα και έχει δίκιο στα 11 (ακρίβεια 0,13). Από τα 14 «Ναι» του ανθρώπου βρίσκει τα 11.
  - Λέει «Ναι» στα μισά λυπημένα κείμενα που δεν έχουν διαστρέβλωση: μπερδεύει τη λύπη με τη διαστρέβλωση.
  - Γι' αυτό η σημείωση στον χρήστη είναι κρυφή (`SHOW_DISTORTION_NOTE=0`).
- **Κούραση:**
  - 0 από 11 στα πραγματικά κείμενα, με AUC ≈ 0,5. Δεν δουλεύει έξω από τα συνθετικά δεδομένα, γιατί καμία πηγή δεν είχε label κούρασης και το μοντέλο την έμαθε μόνο από αυτά.
  - Γι' αυτό η εφαρμογή την κρύβει (`AiClient::HIDDEN_EMOTIONS`): δεν αποθηκεύεται και δεν φαίνεται ούτε στην καταγραφή ούτε στη ζωντανή ανάλυση. Αν ήταν το κύριο συναίσθημα, κύριο γίνεται το επόμενο που περνά το όριο, αλλιώς κανένα.
  - Το μοντέλο δεν άλλαξε. Στο τετράδιο έντονων στιγμών ο χρήστης μπορεί ακόμα να διαλέξει ο ίδιος «Κούραση», γιατί εκεί δεν είναι πρόβλεψη του μοντέλου.

**Δοκιμές χωρίς νέα δεδομένα που δεν πέρασαν** (φάκελος `experiments/`, με τα αποτελέσματα στο README κάθε φακέλου):

- `mixed_sentiment/`: sentiment ανά πρόταση για μικτά κείμενα. Ήταν χειρότερο από την ανάλυση όλου του κειμένου.
- `ensemble/`: ο μέσος όρος δύο seeds. Δεν βελτίωσε τη διαστρέβλωση, και κανένα όριο δεν σώζει την κούραση.
- `distortion_cues/`: η διαστρέβλωση να φαίνεται μόνο με φράση-σημάδι από τον οδηγό. Έκοψε τα λάθη, αλλά έχασε τις περισσότερες πραγματικές διαστρεβλώσεις.

Οι κανόνες απόφασης για κάθε δοκιμή γράφτηκαν πριν από τη μέτρηση.

## Tests

Χωρίς εξαρτήσεις, μόνο PHP:

```bash
php tests/run.php            # όλα
php tests/run.php password   # μόνο όσα ταιριάζουν στο όνομα αρχείου ή test
```

Καλύπτουν router, κωδικούς, ασφάλεια, καταγραφές, API, εξαγωγή δεδομένων, labels, ειρωνεία/διαστρέβλωση, κρίση και ανεκπαίδευτο μοντέλο.

Απαιτήσεις:

- Apache και MariaDB σε λειτουργία, με τα migrations και το `seed.sql` περασμένα.
- Ελεύθερη η θύρα του `AI_SERVICE_URL`. Τα tests ξεκινούν στη θέση της υπηρεσίας AI ένα ψεύτικο server (`tests/fake_ai.php`) για προβλέψιμα αποτελέσματα.
- Για διαφορετική διεύθυνση από το `APP_URL`: `TEST_BASE_URL=...`.

Τα tests χρησιμοποιούν τη βάση του `.env`. Δημιουργούν χρήστες `*@tests.invalid` (σε αυτούς δεν στέλνεται email), τους διαγράφουν στο τέλος και αδειάζουν το `storage/ratelimit`. Μόνο για τοπική ανάπτυξη.

Τα ίδια tests τρέχουν αυτόματα στο GitHub Actions σε κάθε push στο `main` και σε κάθε pull request (`.github/workflows/tests.yml`). Εκεί στήνεται από την αρχή μια άδεια MariaDB 10.4 με το `schema.sql` και το `seed.sql`, Apache με PHP 8.2 και ένα `.env` με τυχαίο κωδικό βάσης και τυχαίο `APP_KEY`.

## Ασφάλεια και ιδιωτικότητα

- **Πρόσβαση:** μόνο ο φάκελος `public/` είναι προσβάσιμος από τον browser. Τα `.env`, `.git`, `storage/` κ.λπ. δεν σερβίρονται.
- **Κωδικοί:**
  - αποθηκεύονται με `password_hash`, με ελάχιστο μήκος 8 χαρακτήρες;
  - οι συνεδρίες ακυρώνονται όταν αλλάξει ο κωδικός.
- **Κωδικοί email:**
  - λήγουν σε 15 λεπτά και δέχονται έως 5 προσπάθειες;
  - νέα αποστολή γίνεται μετά από 60 δευτερόλεπτα.
- **Κρυπτογράφηση κειμένων:**
  - το κείμενο κάθε καταγραφής και τα κείμενα του τετραδίου έντονων στιγμών γράφονται στη βάση κρυπτογραφημένα με AES-256-GCM, με κλειδί το `APP_KEY` του `.env`;
  - προστατεύει αν διαρρεύσει μόνο η βάση (π.χ. ένα αντίγραφο ασφαλείας ή SQL injection). Δεν προστατεύει αν κάποιος πάρει όλο τον server, γιατί εκεί βρίσκεται και το κλειδί;
  - χωρίς κρυπτογράφηση μένουν όσα χρειάζεται η βάση για ερωτήματα: τα ονόματα που βρίσκει το NER, οι βαθμολογίες και τα συναισθήματα, τα insights και οι ημερήσιες συνόψεις;
  - η αναζήτηση στο ιστορικό γίνεται στην PHP, αφού αποκρυπτογραφηθούν οι καταγραφές του χρήστη.
- **CSRF:** προστασία σε κάθε αίτημα που αλλάζει δεδομένα.
- **Rate limiting:**
  - σύνδεση, εγγραφή, επιβεβαίωση email, επαναφορά και αλλαγές λογαριασμού: 5 προσπάθειες ανά 15 λεπτά;
  - αποθήκευση καταγραφών: 20 το λεπτό;
  - ζωντανή ανάλυση: 30 κλήσεις το λεπτό.
- **Security headers:** `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, CSP.
- **Υπηρεσία AI:** ακούει μόνο στο `127.0.0.1`. Οι καταγραφές των χρηστών δεν στέλνονται σε εξωτερική υπηρεσία, εκτός αν ανοίξει το `OPENAI_VERIFY`.
- **Δεδομένα του χρήστη:** μπορεί να τα εξαγάγει όλα και να διαγράψει τον λογαριασμό του.
